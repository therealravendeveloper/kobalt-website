What is Kobalt?

Overview
Kobalt is a monolithic kernel written entirely in C by Abhranil Dasgupta. Every subsystem, from the memory manager to the scheduler to the virtual file system layer, has been designed and implemented from scratch (or Half scratch. Check the Credits) with specific goals in mind:
  • High-throughput High-Level computing environments
  • Low-latency scheduling for Performance inference workloads
  • Security-critical and safety-adjacent applications demanding deterministic behavior
Design Philosophy
  • Monolithic architecture — All core services share a single privileged address space — no IPC overhead, no context-switch tax, just throughput.
  • C only — No C++ in kernel space. Strict aliasing, defined behavior, and predictable codegen are requirements, not goals.
  • No legacy cruft — No decades of accumulated workarounds. The ABI was designed from intent, not inherited from circumstance.
  • Auditable codebase — One engineer should be able to read the entire source in a sitting. Complexity is justified or it isn't there.
